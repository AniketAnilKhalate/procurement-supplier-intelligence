# Walmart Supply Chain Intelligence & Demand Analysis

## Project Overview

This project analyses Walmart retail sales data to explore demand patterns, store performance, and product category trends using SQL and Microsoft Power BI.

The objective is to demonstrate practical data analysis skills relevant to supply chain, demand planning, and retail analytics roles.

## Business Questions

- How does sales volume change over time?
- Which stores generate the highest unit sales?
- Which product categories contribute the most sales volume?
- How can interactive filters help users investigate demand patterns across states and stores?

## Tools & Technologies

- **SQL:** Data validation and exploratory analysis using SQLite.
- **Microsoft Power BI:** Interactive dashboard development and visual reporting.
- **Power Query:** Data transformation and preparation.
- **DAX:** Measures and key performance indicators.

## Dataset

The project uses the publicly available M5 Walmart sales forecasting dataset.

The data includes historical unit sales, calendar information, and weekly selling prices. The current Power BI sales analysis uses the first 90 daily columns as a sample.

**Scope note:** This project analyses sales demand and store performance. It does not directly measure inventory on hand, supplier lead times, or purchase orders because those fields are not included in the current analysis.

## Dashboard Features

- Total units sold KPI
- Distinct product count
- Distinct store count
- Daily sales trend
- Unit sales by store
- Unit sales by product category
- Interactive filters for date, state, store, and category

## Project Structure

- `powerbi/` — Power BI report
- `sql/` — SQL validation and analysis scripts
- `screenshots/` — Dashboard screenshots

## Key Skills Demonstrated

Data validation, data modelling, data transformation, DAX measures, interactive visualisation, and business-focused reporting.

## Future Improvements

- Expand the analysis to the full historical dataset.
- Incorporate weekly selling prices into sales analysis.
- Explore demand seasonality and event-related patterns.
- Develop a documented demand forecasting approach.

## Data Source

The dataset is part of the M5 Forecasting competition hosted on Kaggle: https://www.kaggle.com/competitions/m5-forecasting-accuracy
